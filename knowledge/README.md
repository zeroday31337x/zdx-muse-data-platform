# Public Engineering Knowledge Capsules

These capsules are newly authored, public-safe guidance for the hackathon repository. **They are not exports of the existing ZDX Data Synthesis PostgreSQL knowledge-capsule registry.** Existing private capsule content must be separately retrieved and reviewed for ownership, confidentiality, sensitive data, and publication rights before inclusion.

Capsules are non-executable project reference documents. `AGENTS.md` defines global engineering invariants; `.agents/skills/` defines agent workflows.

Do not treat this documentation as proof of implementation, benchmark performance, model access, or compliance.
